React Food App

Description

A React-based food application that allows users to browse, search, and view details of various food items using a JSON API. The app provides an interactive and user-friendly experience for food lovers.

Features

Fetch and display food items from a JSON API

Search functionality to find specific dishes

Detailed view of each food item

Responsive design for mobile and desktop

Modern UI built with React components

Technologies Used

React.js

JavaScript (ES6+)

HTML & CSS

JSON API
